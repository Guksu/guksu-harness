# 작업 브랜치

기존 호출 이름을 유지하는 Git 준비 절차다. 일반 편집마다 별도로 호출하지 않는다.

- 현재 브랜치·미커밋 변경을 확인하고 팀의 분기 기준과 이름을 따른다. 설정은 `.agents/hooks/branchGuard.config.json`(구버전 `.claude/hooks/`)에 있다.
- 규칙이 없으면 작업에 맞는 `feat/`, `fix/`, `refactor/`, `docs/`를 쓴다. `codex/`는 기본값으로 사용하지 않는다.
- 구현에 필요한 안전한 브랜치 준비는 기존 요청 범위에서 진행한다. 분석만 요청하면 전환하지 않는다.
- 무관한 변경을 버리거나 임의로 stash하지 않는다. 강제 전환·보호 설정 변경으로 차단을 우회하지 않는다.

브랜치 준비 때문에 커밋·푸시 절차를 함께 시작하지 않는다.
