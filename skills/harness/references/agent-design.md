# 선택적 역할 정의

반복해서 재사용하는 역할이 필요할 때만 정의 파일을 만든다. 단발 위임은 작업 범위·입력·기대 결과만 전달할 수 있다. 위임 허용 여부는 현재 앱과 프로젝트 정책을 따른다.

역할마다 목적, 담당 범위, 사용 도구, 입력·출력, 완료 기준을 명시한다. 공유 파일을 동시에 수정할 수 있으면 소유 범위를 나누거나 순차 실행한다. 모델은 현재 세션의 선택을 상속하고 특정 모델을 임의로 고정하지 않는다.

독립 검토는 영향이 큰 변경이나 팀이 정한 검증에 사용한다. 생성자·검증자 분리를 모든 작은 작업에 강제하지 않는다. 팀 규칙은 `docs/harness-rules.md`를 참조하고 전문을 복제하지 않는다.

결과에는 수행 내용, 검증 근거, 미완·실패를 포함한다. 영구 기록은 팀에서 선택했을 때만 종합 담당자가 남긴다.
