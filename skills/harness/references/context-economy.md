# 컨텍스트 사용 점검

스킬 설명과 프로젝트 지침은 팀 고유 결정만 담는다. 일반 개발 상식이나 매번 읽을 문서 목록을 덧붙이지 않는다. 상세 절차는 해당 작업에서만 읽고, 반복 가능한 처리는 스크립트로 실행한다.

큰 로그는 필요한 구간을 추출한다. 위임은 현재 앱과 팀 정책이 허용하고 독립 작업의 이점이 있을 때 사용한다. 문서 크기만으로 실제 토큰 비용·성공률을 추정하지 않는다.

비교할 값은 스킬 설명 길이, 읽은 파일, 실행 시간, 실제 토큰 사용량과 사용자 개입이다. 캐시·요약 동작은 앱 버전에 따라 다르므로 고정 비용 배수나 실시간 예산 보장을 문서에 가정하지 않는다. verifierGate의 maxTokens는 지원되는 transcript의 세션 누적 근사치이며 상세 한계는 `hooks-and-permissions.md`를 따른다.
