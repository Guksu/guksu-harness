# 선택적 프론트엔드 도구

프론트엔드 프로젝트에도 자동으로 품질·배포 절차를 설치하지 않는다. 팀이 선택하거나 해당 점검을 요청할 때 아래 기능을 사용한다. 모두 같은 저장소에 유지하며 별도 패키지 설치를 요구하지 않는다.

| 요청 | 도구 |
|---|---|
| 화면·모션·React 성능 비평과 개선 | `fe-craft` |
| 배포 전 사용자 흐름 계측과 판정 | `fe-predeploy` |
| 기존 UI 패턴 라이브러리 재사용 | `scripts/feSkills.mjs` |

`feSkills.mjs find <요청>`과 `get <slug> --into <대상>`은 선택 기능이다. 팀이 라이브러리를 채택한 경우에만 사용한다. 가져온 코드의 라이선스·출처는 코드 근처나 팀이 정한 기록 위치에 남긴다. 라이브러리를 쓸 수 없으면 작업을 중단하지 않는다.

프로젝트에 스크립트를 복사하거나 게이트를 등록하는 것은 팀이 지속 사용을 선택한 경우에만 한다. 점검 요청만이면 판정까지, 수정도 요청했다면 수정·재검사를 이어간다. 일반 재검사를 위해 loop나 협업 정의를 만들지 않는다.
