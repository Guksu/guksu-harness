# 선택적 협업 진행표

사용자가 협업을 요청하거나 팀의 명시적 절차가 요구할 때만 만든다. 일반 개발·재검사에 필요하지 않다. 앱의 위임 도구와 실제 지원 범위를 먼저 확인한다.

진행표에 필요한 내용:

- 목표와 완료 기준
- 독립적으로 수행할 역할, 입력·출력, 담당 파일
- 순차 의존 관계와 결과를 합칠 담당자
- 실패·중단 시 남길 상태와 재개 위치
- 팀이 요구하는 검증과 기록 정책

## 테스트 시나리오

전체 작업, 한 역할만 재실행, 중간 실패 후 재개를 확인한다. 역할 수를 늘리는 것 자체를 완료 기준으로 삼지 않는다. 검증 결과는 실제 실행 근거와 연결한다.

이미 승인된 구현 범위는 재승인받지 않는다. 기록을 요구하는 팀에서는 종합 담당자가 작업 단위 하나에 모으며, 나머지 팀은 별도 보존 문서를 자동 생성하지 않는다. 특정 플랫폼의 Workflow API나 캐시·재개 기능을 존재한다고 가정하지 않는다.
