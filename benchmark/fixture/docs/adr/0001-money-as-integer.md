# ADR 0001: 금액은 원 단위 정수로 다룬다

- 상태: 채택 (2025-06)

## 배경

초기 버전은 금액을 부동소수점으로 계산해 정률 할인에서 1원 오차가 발생했고, 정산 대사에서 불일치가 생겼습니다.

## 결정

- 모든 금액은 원 단위 `Number` 정수로 저장·계산합니다. `Number.isSafeInteger`로 검사합니다.
- 비율 계산은 `src/lib/money.js`의 `percentOf`만 사용하고 원 미만은 버립니다.
- 표시용 문자열은 응답 직전에만 만듭니다.

## 결과

정산 대사 불일치가 사라졌습니다. 외화 결제를 도입하면 이 결정을 다시 검토합니다.
